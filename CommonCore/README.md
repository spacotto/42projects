# Common Core Projects

## Milestone 0

### [Libft](https://github.com/spacotto/libft) [125/100]
The first project at 42 School. It introduces 42 students to C programming. It aims both to reinforce the skills acquired during the "piscine" phase (selection process) by re-implementing standard library functions and to develop utility functions that will prove valuable throughout their curriculum. By mastering these programming tools, students consolidate their foundations and adopt an efficient working methodology.

## Milestone 1

### [get_next_line](https://github.com/spacotto/get_next_line) [125/100]
Whether dealing with a file, stdin (standard input), or even a network connection, a developer always needs a way to read content line by line. The goal of this project is to develop a program that enables this type of reading—a tool that will prove useful to students throughout their studies.

### [push_swap](https://github.com/spacotto/push_swap) [125/100]
This project requires sorting data on a stack using a limited set of instructions in the fewest possible moves. To succeed, students must select the most appropriate algorithm for optimized data sorting.

### [ft_printf](https://github.com/spacotto/ft_printf) [100/100]
For this project, students must recode the standard library's printf function. They will then be able to reuse it in future projects. This project focuses primarily on variable-length arguments (variadic functions).

## Milestone 2

### [Born2beRoot](https://github.com/spacotto/Born2beRoot) [125/100]
This project introduces the fundamentals of system administration and virtualization through the creation and configuration of a headless server. Students are required to install a Linux system, manage users, access rights, services, and security, and implement various administrative rules to establish a stable and secure environment.

### [Python Modules](https://github.com/spacotto/Python-Modules) [100/100]
This bootcamp offers a progressive learning path to master Python, ranging from the fundamentals (syntax, variables, loops, functions) to advanced concepts (object-oriented programming, error handling, data structures, file handling, polymorphism, packages, design patterns, virtual environments, Pydantic, and functional programming).

### [A-Maze-ing](https://github.com/spacotto/A-Maze-ing) [125/100]
This project involves designing a program capable of automatically generating a maze that adheres to several constraints, and then displaying it in a usable format. Students must work on procedural generation, path management, and construction rules to produce mazes that are coherent, navigable, and compliant with the required specifications.

## Milestone 3

### [Fly-in](https://github.com/spacotto/Fly-in) [125/100]
This project involves designing a routing system capable of simultaneously moving multiple autonomous drones through a dynamic network. Students must work with graph and pathfinding algorithms, manage conflicts, restricted zones, and travel costs, while optimizing the number of turns required to reach the destination efficiently.

### [Codexion](https://github.com/spacotto/Codexion) [100/100]
This project allows students to deepen their understanding of concurrent programming in C through a simulation of limited resource sharing among multiple execution processes. Students learn to work with POSIX threads, mutexes, and condition variables, while implementing scheduling strategies—such as FIFO or EDF—to prevent deadlocks, ensure fair access to resources, and meet system timing constraints.

### [Call Me Maybe](https://github.com/spacotto/CallMeMaybe) [125/100]
This project introduces function calling with language models by transforming natural language instructions into structured function calls. Students learn to produce typed arguments, generate reliable JSON outputs, and employ constrained decoding techniques to effectively link human queries to operations directly executable by a program.

## Milestone 4

### [NetPractice](https://github.com/spacotto/NetPractice) [100/100]
This project offers a hands-on approach to exploring networks, focusing on the manipulation of IP addresses and virtual components. Participants thus gain valuable, practical experience in this essential area of ​​computing.

### [RAG against the machine](https://github.com/spacotto/RAG-against-the-machine) [125/100]
This project involves building a Retrieval-Augmented Generation (RAG) system capable of answering questions about a codebase. Students learn to intelligently chunk documents, index and retrieve relevant information using methods such as TF-IDF or BM25, and then generate reliable answers based on elements actually present in the code.

### [Pac-Man](https://github.com/spacotto/Pac-Man) [100/100]
This project involves recreating the famous arcade game Pac-Man in Python, using a modern, structured architecture. Students must handle game logic, movement, interactions, and various graphical components, while organizing their code cleanly and producing a final version that can be easily deployed and executed.

## Milestone 5

### [Agent Smith](https://github.com/Thomas-Baricault/42--Agent-Smith) [100/100]
This project involves designing an autonomous artificial intelligence agent capable of analyzing a problem, generating code, executing it, and then iteratively improving its solution. Students work on automated reasoning, tool usage, and secure execution within an isolated environment to create a system capable of solving programming challenges with minimal human intervention.

### [The Answer Protocol](https://github.com/42-Projects-Nadoho/The-Anwer-Protocol) [100/100]
This project involves creating a multiplayer text-based adventure game based on a TCP server and a network protocol defined according to RFC conventions. Students work in pairs to implement the 42TAP protocol, develop both command-line and graphical clients, and manage real-time communication, player presence, and an economy of unique items, all while producing a robust implementation and comprehensive technical documentation.

### [Inception](https://github.com/spacotto/Inception) [100/100]
This project deepens the understanding of containerization and system administration using Docker. Students must build and configure multiple Docker images and services on a personal virtual machine, orchestrate their communication, and manage their deployment to establish a coherent, isolated, and reproducible infrastructure.

## Milestone 6

### [ft_transcendence](https://github.com/spacotto/ft_transcendence) [125/100]
This project concludes the core curriculum with the collaborative design of a full-featured web application, the theme of which is freely chosen by the students. The group must implement an interactive interface, manage data, integrate various server-side and client-side functionalities, and use Docker along with several web technologies to produce a functional, well-structured, and online-accessible application.

### [ft_resume](https://www.linkedin.com/in/silvia-pacotto/) [125/100]
This project implies writing a resume for a real IT job posting of your choice, defending it in a mock interview, and setting up a public LinkedIn-style profile—all as practice for real job hunting, self-assessment, and clear professional communication.
